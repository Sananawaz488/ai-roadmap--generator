# 🎓 AI Learning Roadmap Generator

An AI-powered Streamlit application that creates personalized learning roadmaps based on:

- Learning domain
- Current skill level
- Learning duration
- Daily study hours

## Features

- Personalized AI learning roadmap
- Weekly learning plan
- Learning phases
- Practice exercises
- Mini projects
- Final capstone project
- Recommended resource types
- Progress checklist
- Downloadable roadmap

## Tech Stack

- Python
- Streamlit
- Groq API
- OpenAI GPT-OSS 120B
